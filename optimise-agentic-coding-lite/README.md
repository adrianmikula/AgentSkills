# Optimise Agentic Coding Lite

A free Claude Code skill that scans the primary tech stack and produces a 5-layer agentic-coding readiness scorecard with manual quick wins.

## What it does

- Detects the repo's primary tech stack.
- Scores 5 layers of debugging / velocity infrastructure.
- Lists 3–5 manual quick wins.
- Does not auto-apply changes or configure MCP servers.

## Installation

Build locally:

```bash
cd optimise-agentic-coding-lite
bash build-skill.sh
```

Then import the generated `dist/optimise-agentic-coding-lite-skill.zip` into Claude Code.

## Usage

In Claude Code, run:

```
/optimise-agentic-coding-lite
```
