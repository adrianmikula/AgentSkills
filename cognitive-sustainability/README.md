# Cognitive Sustainability Framework

A modular system for maintaining human cognitive engagement and decision authority in AI-assisted development.

---

## Structure

| Directory | Tier | Contents |
|-----------|------|----------|
| `00-core/` | 0 | Always-loaded runtime rules |
| `10-policies/` | 1 | Conditional policy modules |
| `20-profiles/` | 1 | Behavior-tuning profiles |
| `30-metrics/` | 2 | Measurement and scoring |
| `40-frameworks/` | 2 | Deep conceptual documents |
| `50-examples/` | 2 | Example flows and behaviors |
| `90-meta/` | 2 | Framework governance |

---

## Loading Strategy

### Always Load

```
00-core/cognitive-sustainability-core.md
```

### Conditional Loading

| Task Type | Load Policy |
|-----------|-------------|
| Architecture work | `10-policies/architecture-synchronization.md` |
| Security/schema changes | `10-policies/human-decision-boundaries.md` |
| High-autonomy mode | `10-policies/automation-intensity-control.md` |
| Debugging | `10-policies/debugging-engagement-policy.md` |
| Critical systems | `10-policies/high-criticality-systems.md` |
| Learning contexts | `10-policies/active-learning-policy.md` |
| Large codebases | `10-policies/drift-detection-policy.md` |

### Profile Selection

| Mode | Load Profile |
|------|--------------|
| Startup/rapid dev | `20-profiles/startup-mode.md` |
| Enterprise/governance | `20-profiles/enterprise-mode.md` |
| Mentoring/education | `20-profiles/learning-mode.md` |
| Incident response | `20-profiles/incident-response-mode.md` |
| Autonomous agent | `20-profiles/high-autonomy-agent-mode.md` |
