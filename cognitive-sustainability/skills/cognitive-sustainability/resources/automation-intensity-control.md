# Automation Intensity Control

> Tier 1 — Conditional Module. Load when: autonomous agent mode, high-frequency generation, rapid scaffolding, long coding sessions.

---

## Cognitive Budgeting

Allocate cognitive engagement across sessions:

| Session Phase | Target Human Engagement |
|---------------|------------------------|
| Exploration (0-20%) | High — requirements, approach |
| Implementation (20-80%) | Medium — checkpoints, reviews |
| Finalization (80-100%) | High — validation, understanding |

---

## Interruption Frequency Limits

| Action Rate | Max Interruptions | Min Engagement |
|-------------|-------------------|----------------|
| <10 actions/hour | Every 3-5 actions | 15-20% |
| 10-30 actions/hour | Every 5-8 actions | 10-15% |
| >30 actions/hour | Every 8-12 actions | 8-10% |

---

## Engagement Ratios

Track human participation across:

- **Decisions** — % of choices made by human
- **Implementation** — % of code written with human input
- **Validation** — % of results reviewed by human
- **Learning** — % of explanations requested by human

Target aggregate: 10-15% human engagement for routine work, higher for complex work.

---

## Adaptive Automation Rules

| Signal | Automation Response |
|--------|---------------------|
| Rapid approvals | Slow down, increase checkpoints |
| Questions asked | Increase explanatory content |
| Corrections made | Reduce assumptions, seek confirmation |
| Silent acceptance | Reduce output, prompt for engagement |
| Explicit delegation | Increase autonomy, provide summaries |

---

## Fatigue Indicators

Reduce automation intensity when:

- User response time increases significantly
- Responses become minimal ("ok", "sure")
- Multiple corrections in sequence
- Request for "just fix it"
- Session exceeds 90 minutes without break

---

## Session Management

| Duration | Recommended Action |
|----------|-------------------|
| <30 min | Normal pacing |
| 30-60 min | Brief checkpoint |
| 60-90 min | Explicit break prompt |
| >90 min | Mandatory summary + break suggestion |
