# Common Coding Conventions

All AI agents working on this repository must follow the common coding conventions in the [code-conventions-aligner Claude skill](https://github.com/adrianmikula/AgentSkills/tree/main/code-conventions-aligner).

These conventions cover naming, URLs, schemas, CI/CD, git workflow (including commit approval and message drafting), telemetry, error routing, error handling, configuration, testing, security, release, AI autonomy, and documentation.
